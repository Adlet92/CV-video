That was a great experience — very intense.
There, I mainly worked on backend projects using **Golang** and **SQL**, and that’s where I also discovered **frontend development**.
While building my backend projects, I started creating simple interfaces, and I really enjoyed seeing my code instantly come to life in the browser.
That was the moment I realized I wanted to focus on frontend development.

Later, I had the chance to study at **Quantori JS Academy**, where I worked on several **React** projects that helped me grow a lot as a frontend developer.

- Search for specific tasks

Through this project, I learned a lot about **state management** and **API integration** in React.

This project included:

This project helped me improve my understanding of **React hooks**, **routing**, and **modular code structure**.
